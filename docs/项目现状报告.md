### 架构

```
输入 (B, W, C)
  ↓
时频双域预处理：FFT 沿时间维 → (B, freq_bins, C) → 取前 k 个频率分量
                → 展平 (B, k*C) → MLP → (B, W, 64)
  ↓ 拼接 → (B, W, C+64)
多尺度卷积（kernel 3/5/7）→ (B, W, hidden=128)
  ↓
Transformer 编码器（4 头3 层）
  ├→ 重构路径：通道独立、权重共享 → (B, W, C) → max 聚合 → (B, W)
  ├→ 原型路径：作用于重构误差 → (B, W) → max 聚合
  └→ 不确定性估计 → 自适应权重
       ↓
   融合异常分数 (B, W)
```

**max 聚合语义**：任一通道异常 → 该时间点异常。

### 已完成的工程修复

| 问题 | 修复方式 |
|---|---|
| FFT 双重Python 循环 | `torch.fft.rfft` 一行向量化 |
| 原型匹配逐时间步 for 循环 | `torch.cdist` 一次性算完 |
| 设备管理混乱（CPU/GPU 混跑） | 统一 device 传递 |
| 7 个 main 入口、6 个 model 变体 | 单一 `run_ucr.py` 入口 |
| flat import 依赖 CWD | 包内相对导入 |
| 硬编码 UCR_5 权重 0.2/0.8 | `use_fixed_weights` 参数化 |
| 数据路径硬编码 | `--ucr-path` 命令行参数 |
| Top-k 过度宽容 + F1 用真实标签生成预测 | 标准 Top-k + oracle threshold + AUROC |
| 滑窗for 循环 | `np.lib.stride_tricks` 零拷贝 |
| **全链路写死单变量** | **通道化，`n_features` 参数化，新增 `run_mv.py`** |
| FFT 通道平均丢失多变量信息 | FFT 保留通道维 → `(B, k, C)` 展平 → MLP |

### 多变量适配的四个架构决策

| 决策 | 内容 | 理由 |
|---|---|---|
| ① 重构路径 | 通道独立、权重共享（MLP 沿最后一维共享） | 与 MEMTO (NeurIPS'23) 的逐通道处理一致，是该路线标准做法 |
| ② **原型路径** | 作用在**重构误差**上，而非 hidden 特征 | ①语义更贴切：原型匹配的本意就是"离正常原型多远"，重构误差正是直接度量；②通道数天然对齐，无需整除 |
| ③ 分数聚合 | 多变量用 max | 任一通道异常即异常，工业场景常见 |
| ④ 标准化 | 按通道（axis=0）计算 mean/std | 避免 SWaT（51 维，传感器量纲差异大）跨通道污染 |

⚠️ **决策②偏离了 H-PAD (ICLR'25)**——H-PAD 的原型作用在输入/特征上。初版「hidden 切C 段」方案实测失败（`hidden_dim=128` 无法被 SMAP 25 通道 / MSL 55 通道 / WADI 126 通道整除）。若实验效果不理想，可回退到 H-PAD 式方案。

⚠️ **决策③需补消融**：max 聚合对噪声敏感，单通道假阳性会拉高整体分数。消融实验必须补一组 mean 聚合对比。

### 已有结果

| 实验 | 配置 | AUROC | VUS-PR | Top-1/3/5 | F1 |
|---|---|---|---|---|---|
| 冒烟测试（单变量） | 合成数据 | 0.9990 | 0.9917 | 1.0/1.0/1.0 | 0.9409 |
| 冒烟测试（5 通道） | 合成数据 | 0.9997 | 0.9982 | 1.0/1.0/1.0 | 0.9713 |

结果文件：`results/ucr_probe/`、`results/mv/`

### SMAP 失效分析

AUROC 0.4276 < 0.5，**排序反向**。三个原因：

| 原因 | 说明 |
|---|---|
| **max 聚合放大噪声** | 25 个通道取 max，只要任一通道有微小假阳性就拉高分数。异常比例仅 1.06%，被 25 倍噪声淹没 |
| **训练集不含同类异常** | loss 从 0.725 降到 0.601 基本平了（recon 0.238→0.181），模型没学到有区分度的表示 |
| **窗口长度远短于真实周期** | SMAP 是遥测数据，真实周期达数千步，而窗口仅 64 |

**这三条正好对应学术界对重构类方法失效的归因**（详见 `TSAD研究现状调研_2026-10.md` 第三节）：

- (b) 训练集被污染 → 命中
- (d) 窗口长度远短于真实周期 → 命中

**这个失败结果本身就是毕设的切入点** —— 有了「方法在多变量真实数据上失效」的实证，后续引入因果不变性才有对比基准。

## 七、待办清单

### 🔴 优先级最高：复现强基线

调研报告结论：**60% 精力应放在这里**。

原因：目前只有自测数字，没有与公开方法的对比。若加了因果不变性后仍打不过 MEMTO / DCdetector / ScatterAD，整个论文立论就塌了。

需在同一 split、同一指标下复现：
- MEMTO (NeurIPS'23) —— 原型路径的直接前身
- DCdetector (KDD'23) —— 必引强基线，445 次引用
- ScatterAD (NeurIPS'25)

### 🟡 定死实验协议

**leave-one-dataset-out 泛化协议**：在 N-1 个数据集上训练并划分环境，在留出的数据集上测泛化。

原因：跨数据集做环境切分，数学上要求训练集包含多个环境—— 但不可能同时在 SWaT 和 SMAP 上训练再测自己。这是逻辑硬伤，必须用这个协议绕过。

同时确定：
- 至少 3 种环境定义方式（按数据集 / 按时间窗 / 按工况）的对比
- ERM / IRM / MMD / 对抗域不变 四方消融

### 🟡 论文文档口径同步

`docs/thesis/experiments.md` 中的问题：
- Precision/Recall = 1.000 的行是用真实标签搜 oracle threshold 算的 → **学术规范红线**
- "F1 从 0.19 提升到 0.9354（+392.3%）"是自比数据，基线来源不明 → 不可辩护

改法：主报AUROC / VUS-ROC / VUS-PR / Top-k；F1 明确标注 oracle threshold；对比改为与公开方法同 split。

## 八、研究定位（详见 `TSAD研究现状调研_2026-10.md`）

### 方向判定：真空白，不是伪创新

arXiv 全文检索结果：

| 检索式 | 命中数 |
|---|---|
| `"invariant risk minimization" AND "time series anomaly detection"` | **0 篇** |
| `"causal" AND "invariant" AND "anomaly detection" AND "time series"` | 1 篇（有监督，且 invariant 指图结构不变） |

**因果不变性 × 时序异常检测 × 跨数据集泛化** 三个条件同时满足的位置，目前没有已发表论文。

### 必须避开的拥挤方向

| 方向 | 代表工作 | 拥挤度 |
|---|---|---|
| 因果**图**根因分析 | AERCA (ICLR'25 Oral)、OracleAD (NeurIPS'25)、CGAD (TKDD 在投) | 🔴 拥挤 |
| 分布偏移 TTA | M2N2 (AAAI'24)、CANDI (AAAI'26)、COMET (NeurIPS'26) | 🔴 拥挤 |

### 本项目设计恰好踩在最新路线上

| 本项目设计 | 对应顶会工作 |
|---|---|
| 多尺度原型 | H-PAD (ICLR'25) |
| 不确定性加权融合 | **评测空白**（LEFT KDD'26 批评"多数跨视图方法只做分数融合"） |
| 跨数据集泛化 | TimeRadar (KDD'26) 已证明是真问题 |

### 论文切口建议

> 不写"我们提出用因果不变性做时序异常检测"（太宽，会被 CAAD/CGDAD 撞车），
> 写"我们研究**多环境切分粒度对时序异常检测不变表示学习的影响**，并提出环境感知的双路径融合"。
