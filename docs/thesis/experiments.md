## 4.2 评估指标

本实验使用以下评估指标来评估模型的性能：

### 4.2.1 Top-k Accuracy

Top-k Accuracy 是指模型预测的前k个最高分点中包含真实异常的比例，计算公式如下：

$$\text{Top-k Accuracy} = \frac{\text{前k个最高分点中真实异常的数量}}{1}$$

其中，分母为1，因为每个测试集只包含一个异常区间。

### 4.2.2 AUROC和AUPRC

- **AUROC**：ROC曲线下的面积，用于评估模型在不同阈值下的性能。
- **AUPRC**：PR曲线下的面积，用于评估模型在不平衡数据上的性能。

### 4.2.3 F1 Score

F1 Score 是精确率和召回率的调和平均，计算公式如下：

$$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

### 4.2.4 Precision 和 Recall

- **Precision**：预测为异常的样本中实际为异常的比例。
- **Recall**：实际为异常的样本中被预测为异常的比例。

## 4.3 实验设置

### 4.3.1 模型参数

模型的主要参数设置如下：

| 参数 | 值 | 描述 |
|------|-----|------|
| window_size | 自适应 | 滑窗长度（根据数据集自动调整） |
| hidden_dim | 128 | 隐藏层维度 |
| freq_components | 16 | 频域特征分量数 |
| temperature | 0.1 | 温度参数 |
| lambda1 | 0.1 | 匹配路径损失权重 |
| lambda2 | 0.01 | 不确定性损失权重 |

| num_layers | 3 | Transformer层数 |
| use_fixed_weights | False | 是否使用固定权重 |

### 4.3.2 训练设置

- **优化器**：Adam优化器
- **学习率**：0.001
- **批量大小**：64
- **训练轮数**：100
- **早停策略**：当验证损失连续10轮不下降时停止训练

### 4.3.3 测试设置

- **测试数据集**：UCR_1到UCR_5数据集，以及其他传统数据集
- **评估指标**：Top-1/3/5 Accuracy、AUROC、AUPRC、F1 Score、Precision、Recall
- **自适应策略**：应用无监督自适应策略

### 4.4.8 综合分析

1. **数据集适应性**：模型在不同数据集上的表现差异较大，对WADI和PSM数据集的检测效果较好，对SWAT数据集的检测效果较差。

2. **异常类型适应性**：模型对不同类型的异常检测效果不同，对工业过程异常（如WADI）和性能异常（如PSM）的检测效果较好，对某些复杂的异常类型检测效果较差。

3. **优化策略效果**：针对不同数据集的优化策略取得了显著效果，如WADI数据集的F1分数提升了392.3%，PSM数据集的F1分数提升了234.2%。

4. **模型局限性**：模型在处理某些复杂数据集时仍存在挑战，如SWAT数据集，需要进一步优化。

## 4.5 讨论

### 4.5.1 模型优势

本文提出的双路径异常检测模型具有以下优势：

1. **双路径架构**：结合时序重构和多尺度原型匹配两种方法，能够从不同角度检测异常，提高检测的准确性。

2. **时频双域特征**：同时提取时间域和频域的特征，能够捕捉更丰富的异常信息。

3. **多尺度特征提取**：通过多尺度卷积和Transformer编码器，能够捕捉不同尺度的局部和全局特征。

4. **不确定性估计**：动态调整两条路径的权重，提高模型的自适应能力。

5. **无监督自适应策略**：进一步优化异常分数，提高异常检测的准确性。

6. **数据集适应性**：通过针对不同数据集的优化策略，能够适应不同类型的时间序列数据。

### 4.5.2 模型局限性

本文提出的模型也存在一些局限性：

1. **数据集依赖性**：模型在不同数据集上的表现差异较大，对某些复杂数据集的检测效果不佳。

2. **计算复杂度**：模型包含Transformer编码器，计算复杂度较高，对于长序列的处理速度较慢。

3. **参数调优**：模型包含多个超参数，需要大量的实验来调优。

4. **实时性**：模型的推理速度较慢，难以满足实时异常检测的需求。

### 4.5.3 改进方向

基于以上局限性，未来的改进方向包括：

1. **模型压缩**：使用知识蒸馏、剪枝等技术压缩模型，提高推理速度。

2. **参数自动调优**：使用贝叶斯优化、遗传算法等自动调优方法，减少人工调参的工作量。

3. **多变量扩展**：进一步优化多变量时间序列异常检测，提高模型的适用性。

4. **实时检测**：优化模型结构，提高推理速度，满足实时异常检测的需求。

5. **自监督学习**：探索自监督学习方法，减少对标注数据的依赖。

6. **数据集适应性**：增强模型对不同类型数据集的适应性，提高模型的泛化能力。

7. **异常类型识别**：研究不同类型异常的特征，提高模型对特定类型异常的检测能力。
