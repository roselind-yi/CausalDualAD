# 相关工作

## 2.1 传统异常检测方法

传统的时间序列异常检测方法主要包括以下几类：

### 2.1.1 统计方法

统计方法是最早应用于时间序列异常检测的方法之一，主要基于数据的统计特性进行异常识别。常见的统计方法包括：

- **ARIMA模型**：通过建立自回归移动平均模型，预测未来值并计算预测误差，当误差超过阈值时判定为异常。
- **EWMA（指数加权移动平均）**：对历史数据进行指数加权，当当前值与加权平均值的偏差超过阈值时判定为异常。
- **CUSUM（累积和）**：通过累积偏差值，当累积和超过阈值时判定为异常。

统计方法简单直观，但对数据分布有较强的假设，难以处理复杂的非线性时间序列。

### 2.1.2 机器学习方法

机器学习方法通过学习正常模式的特征，识别与正常模式偏离的异常。常见的机器学习方法包括：

- **SVM（支持向量机）**：将时间序列数据映射到高维空间，寻找最优超平面分离正常和异常数据。
- **随机森林**：通过构建多个决策树，综合判断数据是否异常。
- **聚类方法**：如K-means、DBSCAN等，将数据聚类，离群点视为异常。

机器学习方法需要手动提取特征，特征设计的质量直接影响检测性能。

### 2.1.3 深度学习方法

深度学习方法能够自动学习数据的特征表示，在时间序列异常检测中得到了广泛应用。常见的深度学习方法包括：

- **自编码器**：通过编码和解码过程，重构输入数据，当重构误差超过阈值时判定为异常。
- **LSTM（长短期记忆网络）**：捕捉时间序列的长期依赖关系，预测未来值并计算预测误差。
- **GAN（生成对抗网络）**：通过生成器和判别器的对抗训练，生成正常数据的分布，识别偏离该分布的异常。

深度学习方法在处理复杂时间序列时表现出色，但需要大量的训练数据，且模型解释性较差。

## 2.2 双路径模型相关研究

双路径模型在计算机视觉、自然语言处理等领域已经得到了广泛应用，其核心思想是通过两条不同的路径提取不同类型的特征，然后融合这些特征以提高模型性能。在时间序列异常检测领域，也有一些双路径模型的研究：

- **双通道自编码器**：一条路径用于学习数据的低维表示，另一条路径用于学习数据的时序模式。
- **多尺度特征融合**：通过不同尺度的卷积网络提取特征，然后融合这些特征进行异常检测。
- **混合模型**：结合统计方法和深度学习方法，充分利用两种方法的优势。

## 2.3 时频分析在异常检测中的应用

时频分析能够同时捕捉时间域和频域的信息，在时间序列异常检测中具有重要作用：

- **傅里叶变换**：将时间序列转换到频域，分析频率成分的异常。
- **小波变换**：在不同尺度上分析时间序列的局部特征。
- **短时傅里叶变换**：在时间-频率平面上分析信号的时变特性。

时频分析方法能够发现时间域中不易察觉的异常模式，提高异常检测的准确性。

## 2.4 不确定性估计在异常检测中的应用

不确定性估计能够量化模型预测的置信度，在异常检测中具有重要意义：

- **贝叶斯神经网络**：通过概率分布表示模型参数的不确定性。
- **蒙特卡洛 dropout**：在推理时保持dropout激活，通过多次前向传播估计不确定性。
- **集成学习**：通过多个模型的预测结果估计不确定性。

不确定性估计能够帮助模型更好地处理噪声和不确定的情况，提高异常检测的鲁棒性。

## 2.5 小结

综上所述，时间序列异常检测方法不断发展，从传统的统计方法到机器学习方法，再到深度学习方法，检测性能不断提高。双路径模型、时频分析和不确定性估计等技术的应用，为时间序列异常检测提供了新的思路。本文将结合这些技术，提出一种基于双路径模型的时间序列异常检测方法，以提高检测性能。
