# 摘要

时间序列异常检测是数据挖掘和机器学习领域的重要研究方向，在工业监控、金融风控、网络安全等领域具有广泛的应用价值。传统的异常检测方法往往难以捕捉时间序列数据中的复杂模式和异常特征，特别是在面对噪声干扰和多变的异常类型时表现不佳。

本文提出了一种基于双路径模型的时间序列异常检测方法，该方法结合了时序重构和多尺度原型匹配两种路径，能够有效提高异常检测的准确性和鲁棒性。主要贡献包括：

1. **双路径架构设计**：提出了一种融合时序重构和多尺度原型匹配的双路径模型，分别从数据重构误差和原型匹配距离两个角度检测异常。

2. **时频双域预处理**：实现了时频双域特征提取，同时捕捉时间域和频域的异常信息，提高了特征表示的丰富性。

3. **多尺度特征提取**：通过多尺度卷积和Transformer编码器，提取不同尺度的局部和全局特征，增强了模型对复杂模式的识别能力。

4. **不确定性估计**：设计了不确定性估计网络，动态调整两条路径的权重，提高了模型的自适应能力。

5. **无监督自适应策略**：提出了一种无监督的异常分数自适应策略，通过多尺度局部对比度计算和异常候选区域检测，进一步提高了异常检测的准确性。

在UCR时间序列数据集上的实验结果表明，该方法在Top-1/3/5 Accuracy、VUS-ROC、VUS-PR等指标上均取得了良好的性能，优于传统的异常检测方法。

本文的研究成果为时间序列异常检测提供了一种新的思路和方法，具有重要的理论意义和应用价值。未来工作将进一步优化模型结构，扩展到多变量时间序列和实时异常检测场景。
